This folder contains timing (*.m) and parameter (*.txt) files for use with MonkeyLogic, 
corresponding to the single-target and two-target touchscreen tasks described in the publication: 
“Microendoscopic Calcium Imaging in Motor Cortices of macaques during Rest and Movement” 
(Martel et al. 2025 - doi: https://doi.org/10.1101/2024.06.20.599918)

•	Single_target.m and Single_target.txt: Files for the single-target task.
•	Two_target.m and Two_target.txt: Files for the two-target task.

These files are intended to replicate the behavioral paradigms described in the study. 
Please ensure you have MonkeyLogic installed and properly configured to run these tasks
